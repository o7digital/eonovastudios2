# EON NOVA STUDIOS — Header animé

Code de la maquette avec header génératif validé : Ondas, Órbitas, Flujo.

Pour voir la maquette : ouvrir un terminal dans le dossier `site`, lancer `python3 -m http.server 8080` et ouvrir http://localhost:8080.

La maquette est autonome en HTML/CSS/JS, avec des images locales ; les polices Google nécessitent Internet. Le ZIP contient l'état de la maquette historique avec son nouveau header. Les changements éditoriaux pour le site final et la conversion Astro sont détaillés dans INSTRUCTIONS_CODEX.md.

Ce paquet ne contient ni secrets, ni dépendances, ni configuration de l'hébergement privé.
